# Gourmet Menu

صنع بواسطة **Younis** | Made by **Younis**

## الملفات | Files
- `config.js`: اسم المطعم والعملة ونسب السيرفيس والضريبة
- `data.js`: الأصناف والأحجام والأسعار والكود، وتحميل المنيو من الشيت
- `index.html` + `home.js` + `home.css`: الصفحة الرئيسية
- `menu.html` + `script.js` + `menu.css`: المنيو والسلة
- `order.html` + `order.js`: صفحة الأوردر و QR
- `map.html` + `map.js`: صفحة الفروع
- `i18n.js`: الترجمة (إنجليزي / عربي)
- `theme.js` + `theme.css`: الوضع الفاتح / الداكن
- `style.css`: التصميم العام
- `vendor/qrcode.min.js`: مكتبة QR محلية

## الكود | Code format
`0201-0-02` = صنف `0201` + حجم `0` + كمية `02`

- أول رقمين = الكاتيجوري: `01` برجر، `02` بيتزا، `03` باستا، `04` سلطات، `05` سوفت درينكس، `06` هوت درينكس، `07` عصائر
- آخر رقمين = رقم الصنف داخل الكاتيجوري
- رقم الحجم = ترتيب الحجم في الشيت (0 أول حجم)

## المنيو من الشيت | Menu from Google Sheet
المنيو بيتحمّل من Google Sheet. كل صف = حجم واحد. لازم الشيت يكون Anyone with the link (Viewer).

## التشغيل | Run
افتح `index.html` في المتصفح. مكتبة الـ QR محلية، فمش محتاج إنترنت عشانها.

## ملاحظات
- الأوردرات القديمة اللي بالكود القديم (`Pi01-0-02`) مش هتشتغل مع الكود الجديد.
