# Gourmet Menu

## الملفات | Files
- `config.js`: اسم المطعم والعملة 
- `data.js`: الأصناف والأحجام والأسعار والكود
- `index.html` + `script.js`: المنيو والسلة
- `order.html` + `order.js`: صفحة الأوردر و QR
- `style.css`: التصميم

## الكود | Code format
`Pi01-0-02` = صنف `Pi01` + حجم `0` + كمية `02`

- `Pi` = بيتزا، `Bu` = برجر، `Pa` = باستا، `Sa` = سلطات، `So` = سوفت درينكس، `Ho` = هوت درينكس، `Ju` = عصائر
- رقم الحجم = ترتيب الحجم في `data.js` (0 أول حجم)

## التشغيل | Run
افتح `index.html` في المتصفح. صفحة الـ QR بتحتاج إنترنت عشان مكتبة QR.
